# NK Studio weboldal

Statikus weboldal (nkstudio.hu). Vercelen fut, build nélkül.

- `index.html` főoldal, `szolgaltatasok.html`, `blog.html`, `blog/*.html` cikkek
- `ai-felmeres.html` AI-felmérés (azonnali eredmény, HubSpot időpontfoglalás)
- `onfelmeres.html` Önfelmérő térkép (beküldés a Make webhookra, PDF-riport)
- `vercel.json` szép URL-ek (.html nélkül)
